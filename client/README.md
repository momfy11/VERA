# VERA Client (PWA)

## Setup

```
cd client
npm install
```

## Dev server

```
npm run dev
```

Opens at `http://localhost:5173`.

## Features

- React-based UI with responsive grid layout
- Chat, suggestions, and settings panels
- Mock data for baseline UI testing
- WebSocket and API client stubs in `src/lib/`

## Build

```
npm run build
```

Output goes to `client/dist/`.
